# 💸 WassWallet: Control de Gastos y Finanzas

Un sistema integral y ligero para la gestión de finanzas personales. **WassWallet** está diseñado para ser rápido, intuitivo y funcionar en cualquier dispositivo, permitiendo tener un control total sobre tu dinero en el día a día.

## 🚀 Características Principales

*   **Registro Ágil:** Añade ingresos, gastos y transferencias en segundos.
*   **Multiplataforma (PWA):** Interfaz web adaptable que puede instalarse en dispositivos móviles como una aplicación nativa.
*   **Gestión de Cuentas y Deudas:** Monitoreo de saldo en efectivo, cuentas bancarias y control de cupos en tarjetas de crédito.
*   **Presupuestos Inteligentes:** Asignación y seguimiento de límites de gasto por categorías.
*   **Arquitectura Modular:** Lógica separada por vistas para un mantenimiento rápido y escalable.
